# Power BI Sales Dashboard

This project is an interactive dashboard built using Power BI to analyze sales data.

## 📊 Features
- Visualizations using Bar, Pie, and Line charts
- Interactive slicers for filtering data
- Clean and user-friendly dashboard layout

## 🛠 Tools Used
- Microsoft Power BI

## 📁 Project File
- Sales_Dashboard.pbix
